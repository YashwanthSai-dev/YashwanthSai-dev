## About

AI/ML Engineer with ~4.5 years across data science, applied ML, and generative AI. MS in Artificial Intelligence, Saint Louis University.

I build **production LLM systems** — retrieval pipelines that stay accurate under real document volume, evaluation harnesses that catch regressions before users do, and the deployment plumbing that keeps both running. Before GenAI, I spent several years on classical ML at scale: fraud and anomaly detection, marketplace intelligence, gradient-boosted models with SHAP-based explainability.

- **Focus areas** — RAG architecture, agentic workflows, LLM evaluation, MLOps
- **Currently deepening** — vector search at scale, LLM observability, cloud AI infrastructure
- **Ask me about** — RAG that actually retrieves, eval design, moving models from notebook to endpoint
- **Open to** — AI/ML Engineer and Forward Deployed Engineer roles
